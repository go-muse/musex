# Letters

A letter names one of the seven places in the repeating sequence C D E F G A B. One step upward from B reaches C, and one step downward from C reaches B. Moving through seven letter steps returns to the starting letter.

## Order and distance

Counting from C gives each letter a stable ordinal from 0 (C) to 6 (B). The choice of C as the first letter is a convention for listing and sorting. A walk around the circle can start anywhere.

Distance counts steps in a chosen direction. From C to E the upward letter distance is two (C → D → E), and the downward distance is five. The interval number counts both endpoints, so C to E spans a third. Its quality also depends on the accidentals. A letter by itself carries neither an accidental nor an octave.

Combining the letter with an [alteration](alteration.md) gives a [note spelling](spelling.md). C is a specific letter in this model. An uninitialized letter has no place on the circle.
