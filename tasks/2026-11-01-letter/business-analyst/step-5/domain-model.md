# Бизнес-модель: буквы (основные ступени) — пакет `letter`

Обозначения оснований: [Q-N] — ответ человека в questions.md; [roadmap N] — решение N или таблица docs/package-roadmap.md; [ДБ файл раздел] — docs/domain-research.

Изменения относительно v1: правила П-3…П-8 записаны через число букв набора N (для текущего набора N = 7, результаты прежние); обобщение на другие наборы — явное допущение Д-3 со ссылкой из П-13; поправлены потребители (search и modal — косвенные); уточнён термин «обход круга».

## Место в продукте
- MuseX — библиотека музыкальной теории на Go (docs/rules/main.md).
- `letter` — шаг 1 roadmap, начало ветки имён (буква → альтерация → имя); на именах стоит теория этапа 2 [roadmap, таблица №1; решение 17].
- Уровень 0 модели понятий: от системы, строя, нотации, октавы и альтерации не зависит [ДБ 20 раздел 4; ДБ 60 §7].
- Прямые потребители по roadmap (таблица «Прямые импорты»): spelling (3), system (9), notation (13), interval (18). Косвенные — через них: template, mode, search, modal и далее. Их потребности учтены как операции и правила ниже (readiness.md); сами пакеты не прорабатываются [Q-6].

## Глоссарий
| Термин | Значение в модели | Чем не является | Основание |
|---|---|---|---|
| Буква (основная ступень) | один из семи элементов набора букв: C, D, E, F, G, A, B | не символ записи («H», «до», «c» — дело нотации); не ступень лада (I–VII); не позиция и не полутон | [ДБ 10 2.3]; [roadmap 2] |
| Набор букв | все буквы словаря: ровно семь, различные | не каталог, задаваемый пользователем (сейчас) | [Q-5]; [ДБ 10 2.3] |
| Число букв набора (N) | сколько букв в наборе; для текущего набора N = 7 | — | [Q-5] |
| Круг букв | циклический порядок: за каждой буквой следует следующая, за последней (B) — первая (C); начала у круга нет | не порядок по высоте | [ДБ 10 2.3] |
| Канонический порядок | договорной порядок перечня, начинается с первой буквы C: C D E F G A B | не граница октавы системы | [Q-2] |
| Первая буква | C — начало канонического порядка | не граничная буква системы | [Q-2]; [ДБ 11 2.3] |
| Порядковое место | место буквы в каноническом порядке, нумерация с 0: C — 0 … B — 6 (0…N−1); равно буквенному расстоянию вверх от первой буквы | не номер в системе и не pitch class | [ДБ 10 2.3]; [Q-2] |
| Буквенный шаг | переход к соседней букве по кругу | не шаг системы (`Step`) и не ладовый шаг | [ДБ 14 2.2]; [roadmap 13] |
| Буквенное расстояние вверх от X до Y | сколько буквенных шагов вверх по кругу от X до Y: 0…N−1, то есть 0…6 | не ступеневая величина интервала (она = расстояние + 1) | [Q-1 а]; [ДБ 14 2.5 ИТ-2] |
| Буквенное расстояние вниз от X до Y | сколько буквенных шагов вниз по кругу от X до Y: 0…N−1, то есть 0…6 | — | [Q-1 б] |
| Сдвиг буквы на n | буква, до которой доходят от X за n буквенных шагов (n > 0 — вверх, n < 0 — вниз, любое целое) | не перенос ноты на интервал | [Q-1 в]; [ДБ 11 2.3]; [ДБ 14 2.6] |
| Обход круга от буквы X | все буквы набора по кругу букв вверх, начиная с X: X, сдвиг X на 1, …, сдвиг X на N−1 | не обход лада или гаммы [ДБ 15 2.7]; не перебор позиций системы | [Q-2] |
| Недопустимое значение буквы | значение, которое выдаётся за букву, но не является ни одной из букв набора | не «C по умолчанию» | [ДБ 40 ИВ-7]; [ДБ 60 §6] |

## Сущности и бизнес-атрибуты
### Буква
- Природа: значение; тождество — по содержимому: две буквы C — одна и та же буква [ДБ 60 §1].
- Атрибуты: какая это буква из семи; порядковое место (выводится).
- Не содержит: альтерацию, октаву, позицию, частоту, символ записи [ДБ 40 ИВ-1; ДБ 10 2.3].

### Набор букв
- Природа: фиксированный словарь; неизменяем [Q-5; ДБ 60 §5].
- Атрибуты: состав (C D E F G A B), число букв N = 7, канонический порядок, первая буква (C).
- Сейчас существует единственный набор [Q-5].

## Связи
- Набор букв состоит из N = 7 букв; каждая буква принадлежит набору ровно один раз.
- Буквы связаны кругом: у каждой есть следующая и предыдущая.
- Внешние связи (только направление зависимости): имя ноты, система, нотация, интервал используют букву напрямую, лад и далее — через них; буква их не знает [ДБ 20 раздел 4; roadmap, таблица «Прямые импорты»].

## Состояния и переходы
- Нет. Буква и набор — неизменяемые значения: операции дают новый результат и не меняют входы [ДБ 60 §1].
- «Повысить» или «сдвинуть» букву — получить другую букву, а не изменить исходную.

## Операции
Выполняет любой пользователь библиотеки или пакет-потребитель; предусловие всех операций — допустимые буквы.

| Операция | Вход → результат | Основание | Кому нужно |
|---|---|---|---|
| О-1. Перечень | → N = 7 букв в каноническом порядке; число букв | [Q-2] | notation (таблицы символов), system (позиции каждой буквы); косвенно — search, modal (перебор букв) |
| О-2. Обход круга | буква X → N = 7 букв от X по кругу вверх | [Q-2] | system (обход от граничной буквы b, [ДБ 10 2.6 Д2]) |
| О-3. Расстояние вверх | X, Y → 0…N−1 (0…6) | [Q-1 а] | interval (размер вверх = расстояние + 1, [ДБ 14 2.5]); system (h_b(l) = расстояние от b до l, [ДБ 11 2.3]) |
| О-4. Расстояние вниз | X, Y → 0…N−1 (0…6) | [Q-1 б] | interval (размер вниз, [ДБ 14 2.5]) |
| О-5. Сдвиг | X, любое целое n → буква | [Q-1 в] | interval (перенос имени на L шагов, [ДБ 14 2.6]); system (l′ = b сдвинутая на u′, [ДБ 11 2.3]); соседняя буква (n = ±1) |
| О-6. Равенство | X, Y → одинаковы ли | [ДБ 60 §1] | spelling (равенство имён покомпонентно, [ДБ 40 ИВ-1]); косвенно — modal (проверка «семь разных букв», [ДБ 16 §1 п.4]) |

- Порядковое место выводится как О-3 от первой буквы; отдельная операция «буква по номеру / номер буквы» — решение архитектора [Q-3; Q-A1, Q-A4].
- Строковая форма буквы — решение архитектора [Q-4; Q-A4].

## Бизнес-правила и инварианты
Обозначения: ord(X) — порядковое место; N — число букв набора, для текущего набора N = 7 (П-1); mod — математический остаток 0…N−1 (для отрицательных чисел тоже неотрицательный).

- П-1. В наборе ровно семь различных букв: C D E F G A B; N = 7 [Q-5; ДБ 10 2.3].
- П-2. Канонический порядок начинается с C; за последней буквой (B) по кругу следует первая (C) [Q-2; ДБ 10 2.3].
- П-3. Расстояние вверх(X, Y) = (ord(Y) − ord(X)) mod N; вниз(X, Y) = (ord(X) − ord(Y)) mod N. При N = 7 — формула ИТ-2 [ДБ 14 2.5 ИТ-2].
- П-4. вверх(X, X) = вниз(X, X) = 0; при X ≠ Y вверх(X, Y) + вниз(X, Y) = N; вверх(X, Y) = вниз(Y, X) [следствие П-3].
- П-5. Сдвиг(X, n) = буква с местом (ord(X) + n) mod N для любого целого n, в том числе отрицательного и по модулю больше N [Q-1 в; ДБ 11 2.3].
- П-6. сдвиг(X, 0) = X; сдвиг(X, n + N) = сдвиг(X, n); сдвиг(сдвиг(X, n), −n) = X [следствие П-5].
- П-7. сдвиг(X, вверх(X, Y)) = Y; сдвиг(X, −вниз(X, Y)) = Y [связь О-3…О-5; ДБ 14 2.5 «свойства контракта»].
- П-8. Обход от X содержит каждую букву ровно один раз; элемент с индексом i (нумерация с 0) = сдвиг(X, i), i = 0…N−1; обход от C = канонический порядок [Q-2].
- П-9. Буква — значение: равенство по содержимому, независимо от способа получения (сдвиг(C, 9) = E) [ДБ 60 §1].
- П-10. Буква не зависит от системы, нотации, октавы и альтерации; «выше/ниже» для букв не определено — у круга нет начала [ДБ 10 2.3; ДБ 20 раздел 4].
- П-11. Недопустимое значение буквы не подменяется правдоподобным (например, C) и не даёт результата как допустимая буква [ДБ 40 ИВ-7; ДБ 60 §6].
- П-12. Набор, его перечень и порядок неизменяемы для пользователей: действия одного пользователя не меняют результатов для других [ДБ 60 §5].
- П-13. Смысл операций для будущих наборов букв [Q-5]. П-2…П-8 записаны через N. Для текущего набора N = 7, и они дают те же результаты, что формулы базы с «mod 7». Для набора с другим числом букв смысл операций задаёт допущение Д-3, а не проектирование. Само расширение не реализуется.

## Отклонения от предметной области
- В поведении — нет.
- Пояснение 1. Канонический порядок от C — договорной (у круга нет начала); база называет C традиционным началом отсчёта, а граничную букву — параметром системы [ДБ 10 2.3; ДБ 11 2.3]. Пакет `letter` граничной буквы не знает.
- Пояснение 2. Требование «не мешать будущим наборам букв любого количества» [Q-5] шире базы: там словарь модели — семь букв, иные наборы — открытый вопрос И-3; литература о наборах с другим числом основных ступеней молчит [ДБ 10 2.3; ДБ 70 И-3; evidence/lit-pitch 1.11.8]. Поэтому смысл операций для таких наборов — допущение Д-3, а не доменный факт. Это ограничение на решение, а не изменение модели для семи букв; И-3 остаётся открытым.

## Допущения
- Д-1. Обход — только вверх по кругу (пример в Q-2: A B C D E F G); обход вниз получается сдвигом на −1 и отдельной операцией не вводится. Не влияет на потребителей (system обходит вверх) [readiness.md].
- Д-2. Порядковые места 0…6 — термин модели для формул; что из них станет частью публичного API — решение архитектора [Q-3].
- Д-3. Обобщение на набор из N букв (будущее, вне объёма). Основание: Q-5 (расширение не должно встретить препятствий) при молчании литературы (И-3; evidence/lit-pitch 1.11.8). Принимается:
  - набор — N ≥ 1 различных букв с договорным каноническим порядком; буквы образуют круг: за последней следует первая;
  - порядковые места 0…N−1; расстояния вверх и вниз — в 0…N−1 по П-3; сдвиг — по П-5 с периодом N; обход — N элементов по П-8; равенство — по П-9;
  - при N = 7 и текущем наборе все результаты совпадают с П-1…П-12;
  - частный случай N = 1: расстояния всегда 0, сдвиг на любое n возвращает ту же букву.
  - Не определяется (вне объёма, И-3): какие наборы бывают, их буквы и первая буква; операции между буквами разных наборов; влияние на системы, интервалы и нотации.
  - Допущение не превращает гипотезу в доменный факт; при исследовании И-3 его нужно перепроверить.
