## Наблюдения (неблокирующие)
- **Н-1. Ёмкость среза `Cycle` не проверяется тестом.** Контракт и doc-комментарий `Cycle` обещают «length and capacity Count». Тесты проверяют ёмкость `All()`, а для результата `Cycle` — длину и независимость копий. Мутация, при которой `Cycle` возвращает срез с ёмкостью 8, все тесты проходит. Поведение реализации верно (ёмкость 7 подтверждена сценарием QA), эффект — только пробел в тесте. Серьёзность: низкая. Рекомендация автору тестов: добавить проверку ёмкости результата `Cycle` для каждой начальной буквы; на текущей реализации тест пройдёт. Приёмку не блокирует.
- **Н-2. `ErrInvalid` — экспортируемая переменная** (`var`, принятое решение architecture, как `io.EOF`). Любой код может переприсвоить её. Это принятый приём Go и решение архитектора, не нарушение К-13 (в самом пакете нет изменяемого состояния, изменить его можно только явным присваиванием в коде пользователя). Замечание информационное, действий не требует.
- **Н-3. Тестовые файлы без `t.Parallel()`:** `example_test.go` и `helpers_test.go` (примеры Go его не допускают; помощники — не тесты). Во всех тестах верхнего уровня, где это возможно, `t.Parallel()` используется (`letter_test.go` — 45 вызовов, `invalid_test.go` — 14, `concurrency_test.go`, `imports_test.go`). Правило docs/rules/dev-test.md соблюдено.
