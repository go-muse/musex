# Постановка задачи: пакет `letter` (шаг 1 roadmap)

## Исходный запрос
Человек, 2026-11-01: «Изучи docs/package-roadmap.md и текущее состояние выполнения задач. Начни первую незавершённую задачу с готовыми зависимостями по настроенному процессу.»

## Цель
- Продукт: MuseX — библиотека музыкальной теории на Go (`github.com/go-muse/musex`), новая реализация на замену `muse` (docs/rules/main.md).
- Задача: пакет `letter` — первый шаг roadmap. Основание выбора: в репозитории нет Go-пакетов, в ROADMAP.md ни один пункт не отмечен; у `letter` нет прямых импортов.
- Для кого: пользователи библиотеки и последующие пакеты musex.

## Контекст
- Место в roadmap: №1, обязанность «семь основных ступеней, их циклический порядок, буквенное расстояние».
- Будущие потребители (другие шаги roadmap, не входят в задачу): spelling (3), system (9), notation (13), interval (18) и далее. Учитываются только их известные потребности к `letter` (readiness.md), без проработки самих пакетов.
- Доменная база: docs/domain-research; старый проект — только через MCP gokg_muse, не эталон.
- Правила разработки: Go 1.27.3, golangci-lint v2.15.0, Must-обёртки, pointer receivers, без vendor; тесты — Testify, t.Parallel(), табличные; ветка `feat/1-<описание>`.

## Ожидаемый результат
- Форма: Go-пакет библиотеки `letter` с публичным API, тестами, документацией и примерами; проверен ревью и QA.
- Функции (основание — ответы человека, questions.md):
  - семь букв; канонический порядок начинается с первой буквы (C) [Q-2];
  - перечень семи букв в каноническом порядке и обход круга от любой буквы [Q-2];
  - буквенное расстояние вверх по кругу (0…6), расстояние вниз, сдвиг на любое целое число шагов по кругу; результат — число буквенных шагов [Q-1];
  - только 7 букв, но решение не должно мешать будущему добавлению наборов букв любого количества [Q-5].
- Документация: README, примеры Go (examples) и прочая документация пакета [Q-7]; отметка пункта 1 в ROADMAP.md — после приёмки.
- Признаки успеха: принятые требования и API; полный набор тестов принят до реализации; QA «принять»; приёмка человеком.
